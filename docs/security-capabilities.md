## 지원 기술의 정확한 의미

- TypeScript/JavaScript: 공식 TypeScript6.0.3 parser로 문자열만 파싱. React/Vite 화면 파일은 서버 인증 흐름이 아닙니다.
- Next: 선언된13.2~16의 제한 App Router route.js/ts; 14+ async use server. Pages API·전체 React.cache/Proxy/wrapper·실제 Action 호출·빌드 bundle은 보증하지 않습니다.
- Deno: 직접 Deno.serve와 고정 std@0.x.y/http/server.ts serve. Supabase verify_jwt 선언과 실제 gateway/로그인 성공은 다릅니다.
- Express: 출처 확인 정적 등록/Router/helper와 제한된 CommonJS·ESM 전달. 전체 middleware·event·class runtime 엔진이 아닙니다.
- Sequelize4~6, Mongoose4~8은 선언/API 계약입니다. 설치 버전이나 모든 API 지원이 아닙니다. Mongoose callback은4~6, 7+는 별도 미지원입니다.
- Python: Django/DRF의 선택된 진입점·SQL·파일·역직렬화·토큰·권한 근거. Java: Servlet/Spring 입력과 선택 JDBC/JdbcTemplate/Mapper SQL 계약. 공통 웹 앱 전체 지원으로 확대 해석하지 않습니다.
- Supabase: Client/쓰기 필드/사용자 근거와 저장소 RLS·GRANT·컬럼 UPDATE 선언. 운영 DB·실제 JWT 역할·소유자 요구사항은 미확인입니다.
- SCA: npm/PyPI/Maven/Gradle 식별자·버전·OSV 결과. Docker image 전체 SCA, 실제 설치/도달 가능성/업데이트 호환성은 보장하지 않습니다.

## 수정 기능 경계

- 결정적 수정: **TS_SENSITIVE_DATA_EXPOSURE 전체가 아니라**, 원본/Finding/hash/revision이 맞는 직접 지원 Deno Response.json 객체의 환경값 필드 제거만 지원. 정상 필드가 남아야 하며 API 호환성 확인과 명시적 승인이 필요합니다.
- AI 패치: 단순 .properties의 DEBUG_ENABLED/STACKTRACE_EXPOSURE/INSECURE_COOKIE 값 변경 및 기존 제한 Deno 계약. 실제 모델 품질은 Mock 검증과 구분합니다.
- 수동 편집·Diff·승인·ZIP/Patch·STANDARD 재검사는 공통 기능입니다. 그것이 모든 취약점의 원인에 맞는 자동 수정 또는 정상 기능 유지 검증은 아닙니다.
- 구조 Finding은 REVIEW_REQUIRED/NOT_COMPARED. 사라졌다고 RESOLVED로 자동 계산하지 않습니다. ZIP 원본 동일성 미검증이면 과거 자동 해결 비교를 하지 않습니다.
- SCA 고정 버전과 권고는 보안 공지 메타데이터입니다. 의존성 설치·lock 재생성·RLS 정책 자동 적용을 하지 않습니다.
