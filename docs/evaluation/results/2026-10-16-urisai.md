## 5. 결과 밖의 주요 흐름 3개

### OIDC 입력 → 세션 → 변경 API

`worker/auth.ts:202-221`의 callback은 state 쿠키 일치와 DB 일회성 삭제를 확인한다. `228-260`은 PKCE verifier, 고정 token endpoint, RS256/issuer/audience/nonce/만료 검증이다. `288-295`는 무작위 세션의 hash를 저장하고 쿠키를 발급한다. `41-47`, `93-109`, `125-135`에서 HttpOnly/Secure/세션 만료/Origin/CSRF 검사를 확인했다.

Rule 결과는 0이나 이 구조를 이해해 안전 판정한 것은 아니다. `allowed()`의 빈 allowlist 허용은 README가 설명한 공개 가입 정책과 일치하므로 인증 우회 미탐으로 보지 않았다. 운영 secret/HTTPS/Google 설정과 실제 거부 요청은 미검증이다.

### 인증 사용자 → 공간/초대 → D1 조회·갱신

`worker/index.ts:115-117`에서 인증과 변경 요청 CSRF 검사를 거친다. `63-108` snapshot은 인증된 user.id의 pair_id로 범위를 제한한다. `268-309` 초대 가입은 코드 형식/해시/만료/issuer 소속/정원/빈도 제한 및 parameter binding을 사용한다. `migrations/0001_initial.sql:12-17`에 DB 정원 trigger가 있다.

판정: 제한된 정적 검토에서 IDOR/SQL injection을 확정할 근거를 찾지 못했다. 동시 가입/탈퇴/로그아웃 경합은 대상 테스트를 실행하지 않아 미검증이다. SQL 문자열이 있다는 이유로 위험하다고 처리하면 `.bind()`와 trigger 방어를 놓친다. 현재 엔진은 Worker 의미와 SQL migration을 연결하지 못한다.

### 위치 업로드 → 공유 권한 → 화면/캐시

`worker/index.ts:189-235`는 좌표 범위/시각/epoch/세션과 공유 상태를 조건부 SQL에 묶고 `259-265`에서 공유 중단과 위치 삭제를 처리한다. `src/MapView.tsx:103-117`은 nickname을 textContent로 넣은 DOM node를 Leaflet에 전달한다. `public/sw.js:25-33`은 API/auth/외부 origin을 캐시 처리에서 제외한다.

판정: XSS·개인정보 API 캐시 노출의 명확한 미탐을 확인하지 못했다. 동시 요청·다른 기기·실제 CDN/Workers 보안 헤더는 미검증이다. `public/_headers`가 엔진에서 제외되므로 헤더의 존재와 실제 적용을 제품이 설명할 수 없다. 이런 미검증 영역을 확정 취약점으로 기록하지 않는다.
